# Audit ergonomique assisté

Application d'aide à la relecture des audits ergonomiques (heuristiques) réalisés par les UX designers.

- `CONCEPTION.md` : document de conception (fonctionnalités, architecture, règles de départage, score, feuille de route)
- `referentiel/source/` : fichiers CSV d'origine (grille des critères et frameworks heuristiques)
- `referentiel/referentiel.json` : référentiel structuré, généré par le script ci-dessous
- `scripts/build_referentiel.py` : conversion des CSV en JSON (`python3 scripts/build_referentiel.py`)
